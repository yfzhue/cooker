# cooker

`cooker` 是一个面向科研与专业知识库构建的文献智能系统设计仓库。当前重点不是做通用笔记工具，而是沉淀一套可工程落地的 **自动文献调研、严格来源引用、证据约束生成、低幻觉评测与审计规范**。

## 核心目标

- 自动完成文献检索、筛选、评估、综合与引用导出。
- 为专业知识库构建 `paper -> span -> claim -> evidence -> conflict -> review` 的结构化证据层。
- 执行 **No Unsourced Claim** 策略：最终输出中的每条关键断言必须具备明确来源引用。
- 通过 P0 指标、SQL 口径、红队测试与专家复核持续约束幻觉风险。

## 设计固化状态

当前设计已达到 **v1 可固化** 状态：可以作为研发、算法、产品和专家评审的共同基线进入实现阶段。后续变更应通过版本化文档、评测指标和发布门禁管理，而不是继续停留在开放式讨论。
